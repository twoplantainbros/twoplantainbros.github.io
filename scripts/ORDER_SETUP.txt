Gambit orders: Stripe FIRST, then Google Sheet (recommended)
=============================================================

Customers pay on Stripe before a row is added. The Google Form is optional / legacy;
paid orders go straight into the same Sheet via Apps Script.

A) Sheet column layout (add column P if needed)
------------------------------------------------
Row 1 headers (match your Form sheet or add manually):
  A Timestamp | B Salt | C BBQ | D Churro | E Total bags | F Order total USD
  G Name | H Email | I Phone | J Street | K Apt | L City | M State | N ZIP | O Notes
  P Status (paid) | Q Stripe session ID

B) Stripe: $6 bag price
------------------------
  Test:  STRIPE_SECRET_KEY=sk_test_... python3 scripts/create-stripe-bag-product.py
  Live:  STRIPE_SECRET_KEY=sk_live_... python3 scripts/create-stripe-bag-product.py
  Save the printed price_id (price_...). Test and live price IDs are different.

  Production (Apps Script Script properties, NOT Google Form):
    STRIPE_SECRET_KEY      = sk_live_...
    STRIPE_PRICE_ID        = live case price_... ($6/bag, 6+ case checkout)
    STRIPE_PRICE_ID_SOLO   = live solo price_... ($11.25/bag, 1–5 on buy.html)
  Redeploy web app (new version). order-config.json unchanged unless /exec URL changes.

C) Apps Script (on the ORDERS spreadsheet)
-------------------------------------------
1. Open your orders Google Sheet → Extensions → Apps Script.
2. Replace code with scripts/gambit-order.gs (copy/paste).
3. Project settings → Script properties, add:
     STRIPE_SECRET_KEY    = your Stripe secret key (same as STRIPE_SECRET_KEY env)
     STRIPE_PRICE_ID        = price_... case (see stripe-order-config.json)
     STRIPE_PRICE_ID_SOLO   = price_... solo ($11.25)
     WEB_APP_URL          = (paste after step 4; must match deploy URL exactly)
4. Deploy → New deployment → Web app
     Execute as: Me
     Who has access: Anyone
   Copy the /exec URL → set WEB_APP_URL to that exact URL (same value).
5. Update deployment if you change code (Manage deployments → Edit → New version).

D) Website: order-config.json
------------------------------
  "checkoutMode": "stripe",
  "appsScriptCheckoutUrl": "https://script.google.com/macros/s/XXXX/exec"

Leave googleForm block in place for reference; stripe mode skips Form POST.

E) Test (test mode)
-------------------
1. Site: 6+ bags, shipping, Submit → Stripe Checkout test card 4242 4242 4242 4242.
2. After pay → redirect to gambitchips.com/?paid=1
3. New Sheet row, Status = paid, Stripe session ID filled.

F) Google Form only (no Stripe)
-------------------------------
  "checkoutMode": "form"
  Submit POSTs to Form → Sheet (no payment). Use for testing or manual invoicing.
